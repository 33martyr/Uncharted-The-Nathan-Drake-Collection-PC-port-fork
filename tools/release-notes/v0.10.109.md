**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 2 multiplayer (test)

- **The Multiplayer tab now works like Uncharted 3's.** A "Ready for multiplayer" checklist and the same four setup
  steps: 1. your PS3 Uncharted 2 GOTY folder (1b. RPCS3's game data folder, 1c. the community server DNS, the same box
  as Uncharted 3's), 2. the decrypted EBOOT, 3. where the files go (the "U2 Multiplayer" folder: Change / Open),
  4. Import, with its progress and status.
- Everything from 0.10.108: the "U2 Multiplayer" folder laid out like "U3 Multiplayer", faster import updates (thanks
  to Tha14, #14), and no Python in the package.
