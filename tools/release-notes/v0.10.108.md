**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 2 multiplayer (test)

- **Import it from the Multiplayer tab.** Choose Uncharted 2, open the Multiplayer tab, pick your PS3 Uncharted 2 GOTY
  folder and RPCS3's game data folder, then press **IMPORT** (a few minutes). Uncharted 2 starts with multiplayer once
  the import has finished.
- **A "U2 Multiplayer" folder, like "U3 Multiplayer".** The import goes next to your Uncharted 3 multiplayer folder,
  with the same layout (`image`, `recipe`, `tools`, `state.json`, `import.log`). **Change** and **Open** under Storage
  pick and show the folder. Your Uncharted 2 multiplayer progress and saved films are kept where they were.
- An Uncharted 2 import from before this version is not used any more: press **IMPORT** once.
- **Faster import updates** (thanks to Tha14, #14): files that did not change are no longer read and checked again.
  The result is byte for byte the same.

## Launcher

- **No Python in the package any more.** The launcher, its updater and both imports are native programs.
