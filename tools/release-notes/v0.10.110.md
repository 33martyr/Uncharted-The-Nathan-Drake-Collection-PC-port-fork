**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **Multiplayer helper v7.213.** Every part of the helper that follows the game's own rules is now written again from
  a description of what it does, in C++, and checked against the previous helper with automated tests. The helper is
  also built with our own C++ tools only. It should play exactly like 0.10.109; please report anything that differs.
- After the update the launcher rebuilds your multiplayer image once (about a minute); your progress is kept.

## Launcher

- **New icon:** Nathan Drake, with rounded corners and sized like the other taskbar icons. The game windows use it too.
  If a pinned taskbar shortcut keeps the old icon, unpin it and pin it again.
